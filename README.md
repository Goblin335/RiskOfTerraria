# RiskOfTerraria
Мод для игры террария, в большинстве своём тут кастомная музыка имеет АП, естественно это не коммерческий, открытый проект. Как создатель этого мода, я разрешаю брать из него какой либо код и механики, с условием что в вашем коде, в комментарии укажите изначального разработчика этой идеи, спасибо за понимание!

Некоторое ньюансы: 
- пока что мод не рассчитан на многопользововательскую игру, что возможно будет исправлено, если этот проект понравится пользователям. 
- возможны некоторые баги и недочёты, это связанно с неопытностью разработчика что я признаю.
